# MegaBlog

A full-stack blogging application built with **React** and **Appwrite**. 
Users can sign up, log in, and create, edit, or delete their own blog posts 
with support for image uploads and rich text formatting.

## Features
- 🔐 User authentication (Sign up / Login)
- ✍️ Create, edit, delete blog posts
- 🖼️ Image upload via Appwrite storage
- 📄 View all posts / individual post pages
- 🎨 Responsive UI with Tailwind CSS

## Tech Stack
- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Appwrite (Auth, Database, Storage)
- **State Management:** Redux Toolkit 

## Getting Started
\`\`\`bash

npm install

npm run dev
\`\`\`

Create a `.env` file based on `.env.sample` and add your Appwrite credentials.
